# wailbox — portfolio

Bilingual (EN/AR) personal portfolio for Wail Abualela, PHP & Moodle engineer.
Editorial dark design on OLED black. React 19 + TypeScript + Vite + Tailwind v4 + Motion.

## Run locally

```bash
npm install
npm run dev        # http://localhost:3000
```

## Build

```bash
npm run build
npm run preview
```

## Docs

- `DESIGN.md` — the design system (tokens, typography, motion, rules)
- `CLAUDE.md` — architecture notes for AI-assisted development
